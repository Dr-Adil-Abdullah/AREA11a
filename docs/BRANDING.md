# دکان کا نام اور ائیکن — App name & icon (v0.59.0)

یہ Settings کے الگ ٹیب **App name & icon** میں ہے (Shop details میں نہیں)۔
صرف مالک بدل سکتا ہے۔

## نام کہاں نظر آتا ہے

- ہر کھڑکی کے اوپر (ٹائٹل) — اور اسی سے **ٹاسک بار** میں
- لاگ اِن سکرین پر بڑا نام
- نیا نام 1 سے 40 حروف؛ خالی نہیں ہو سکتا

## ائیکن کہاں نظر آتا ہے

- ہر کھڑکی کے اوپر بائیں کونے میں، لاگ اِن سکرین پر بڑا، اور ٹاسک بار میں
- صرف Windows `.ico` فائل، زیادہ سے زیادہ 2 MB
- چنی ہوئی فائل photos فولڈر میں رہتی ہے، اس لیے photo والے بیک اپ میں ساتھ جاتی ہے

## پرچیاں اور WhatsApp

- نام: دکان کا نام (**Shop details** والا) پہلے سے ہر پرچی اور ہر WhatsApp پیغام پر آتا ہے
- تصویر: کاغذ کی پرچی اور WhatsApp میں logo کی **تصویر** نہیں آتی (پرنٹر صرف لفظ چھاپتا ہے،
  WhatsApp پیغام صرف لفظ ہوتا ہے) — مالک کا فیصلہ ہے کہ ابھی یہی کافی ہے

## سچی حد (honest limits)

- جو شارٹ کٹ ٹاسک بار میں **pin** ہے اس کی تصویر نہیں بدلتی — وہ انسٹال شدہ پروگرام کی ہے۔
  چلتی کھڑکی اور اس کا ٹاسک بار بٹن آپ کا ائیکن دکھاتے ہیں۔
- پرانے ڈائیلاگ (چھوٹی کھڑکیاں) ابھی بھی "Area11" لکھتے ہیں؛ بڑی کھڑکیاں اور لاگ اِن آپ کا نام۔
- ورژن بیج (v0.59.0 Aegean) جانچ کے دنوں میں ساتھ رہتا ہے تاکہ ہر رپورٹ میں پتہ چلے کون سا ورژن تھا۔

## Physical check (test copy، تقریباً 5 منٹ)

1. App name & icon ٹیب میں نام بدلیں، Save — ہر کھڑکی اور ٹاسک بار کا نام بدلے
2. `.ico` چنیں — لاگ اِن سکرین، کھڑکیاں، ٹاسک بار سب پر نیا ائیکن
3. پرچی پرنٹ کریں اور WhatsApp پیغام دیکھیں — دکان کا نام اوپر ہو
4. کیشیئر سے لاگ اِن — نام اور ائیکن بدلے نہ جا سکیں

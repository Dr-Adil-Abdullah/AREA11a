>
> آپ کے `D:\areaa` فولڈر میں **`Area11.sln` موجود ہی نہیں**۔ اسی لیے بلڈ نہیں ہو رہا اور
> Visual Studio پرانا `Area11.WPF.csproj` ڈھونڈتا رہتا ہے۔
>
> آپ کے فولڈر میں پرانی اور نئی فائلیں **ملی جلی** ہیں:
> `Area11.WPF`، `WPFSample` اور `Area11.WPF.sln` پرانی نسخے کی باقیات ہیں، جبکہ اصل سولوشن
> `Area11.sln` کبھی آپ کے فولڈر تک پہنچا ہی نہیں۔ ایسے فولڈر کو ٹھیک کرنے کا سب سے محفوظ طریقہ
> **تازہ کاپی** لینا ہے۔

## صرف تین قدم (کچھ ٹائپ نہیں کرنا)

### قدم 1 — یہ لنک کھولیں

```
https://github.com/Dr-Adil-Abdullah/AREA11a/archive/refs/heads/arena/a8a3b2e0-area11a.zip
```

براؤزر فائل ڈاؤن لوڈ کرے گا (`AREA11a-arena-a8a3b2e0-area11a.zip`)۔

### قدم 2 — ایکسٹریکٹ کریں

ڈاؤن لوڈ شدہ فائل پر **رائٹ کلک → Extract All…** → راستہ `D:\` رکھیں → **Extract**۔

نیا فولڈر بن جائے گا: **`D:\AREA11a-arena-a8a3b2e0-area11a`**

### قدم 3 — اُس نئے فولڈر میں

**`START-AREA11.bat`** پر ڈبل کلک کریں۔

یہ خود بلڈ کر کے ایپ چلا دے گا۔ سائن اِن: نام **خالی**، پاس ورڈ **`area11`**۔

> آپ کا ڈیٹا محفوظ ہے — وہ `C:\ProgramData\Area11` میں رہتا ہے، کسی فولڈر کی نقل و حرکت سے
> متاثر نہیں ہوتا۔ پرانا `D:\areaa` فولڈر بعد میں حذف کر سکتے ہیں (ابھی رہنے دیں)۔

## دکان کے کمپیوٹر پر (انسٹالر والا طریقہ)

اپنے بلڈ کمپیوٹر پر (جہاں Visual Studio ہے) ایک بار:

1. `tools\MAKE-INSTALLER.cmd` پر ڈبل کلک — یہ خود بلڈ کر کے `dist\Area11-setup` فولڈر بناتا ہے
   (تقریباً دو منٹ)۔
2. وہ فولڈر (یا `dist\Area11-setup.zip`) USB پر دکان کے کمپیوٹر پر لے جائیں۔

دکان کے کمپیوٹر پر:

3. فولڈر کھولیں (زپ ہو تو پہلے **Extract All**) اور **`INSTALL-AREA11.cmd`** پر ڈبل کلک۔
4. ونڈوز اجازت مانگے گی → **Yes**۔
5. سکرین پر لکھا آئے گا کہ کیا ہو رہا ہے، اور Area11 خود کھل جائے گی۔ ڈیسک ٹاپ پر آئیکن بھی بن جائے گا۔

> **آپ کا ڈیٹا `C:\ProgramData\Area11` میں ہی رہتا ہے۔** اپ ڈیٹ کا طریقہ یہی ہے: نیا انسٹالر بنا کر
> وہی فائل دوبارہ چلائیں۔ اَن انسٹال کرنے پر بھی ڈیٹا نہیں مٹتا — Area11 دوبارہ لگانے پر وہی بل، وہی
> کھاتے ملتے ہیں۔ تفصیل: [INSTALL.md](INSTALL.md)۔

6. **پرنٹر اور سکینر کی جانچ** — Area11 میں **SYSTEM → Printer & scanner** کھولیں: *Print test slip*
   دبائیں اور کاغذ دیکھیں (پیمانے کی لائن پوری ہونی چاہیے: 58 mm پر 32 حروف، 80 mm پر 48)؛ پھر ایک دوا کا
   ڈبہ سکین کریں، چھ ٹک لگائیں اور **Save the result** دبائیں۔ کاغذ یا پرنٹر بدلیں تو یہ جانچ دوبارہ کریں۔

## کلاؤڈ سنک (اختیاری)

اگر آپ گھر سے دکان کے نمبر دیکھنا چاہیں تو **SYSTEM → Cloud sync** — پہلے

**Push**؛ "Bring" صرف نئی مشین پر پرانا ڈیٹا لانے کے لیے۔

## غلط ہجے والی دوا بھی مل جاتی ہے

کاؤنٹر پر نام ہمیشہ ٹھیک لکھا نہیں جاتا۔ اب **ایک حرف کی غلطی** سے دوا نہیں چھوٹتی:

- `panadl` لکھیں → لسٹ میں **Panadol 500mg** اور اوپر نمایاں سطر: *"Nothing is spelt \"panadl\"… Check the box before you bill it."*
- `augmnetin` (دو حروف اُلٹے) → **Augmentin**
- `omeprazol` (سالٹ سے) → **Risek**

> **یہ اندازہ ہے، جواب نہیں۔** ٹوکری میں ڈالنے کے لیے **Add to cart** خود دبائیں؛ سرچ باکس میں **Enter** صرف
> بارکوڈ سکین کرتا ہے اور کوئی اندازہ بل میں نہیں آتا۔
>
> بہت غلط ہجے یا چار حرف سے چھوٹے نام (Zinc, ORS) صرف درست ہجے پر ملیں گے — یہ حفاظت ہے، تاکہ غلط ڈبہ نہ اُٹھے۔

## نئی دکان میں نمونہ ڈیٹا (صرف آزمائش کے لیے)

بالکل نئی Area11 خالی ہوتی ہے — ہر صفحہ "کچھ نہیں" کہتا ہے۔ نمونہ دیکھنے کے لیے:

1. **SYSTEM → Sample shop** کھولیں۔
2. لکھی ہوئی فہرست پڑھیں، پھر ٹک لگائیں **"I understand this is demo data…"**۔
3. **Fill this shop with the sample shop** دبائیں — بس۔

اب **Counter (POS)** پر 20 دوائیں، **SELL → Bills** پر 12 بل، گاہکوں پر کھاتہ، اور رپورٹس میں تین ہفتے کا کام نظر آئے گا۔

> **یہ صرف اُس دکان میں چلتا ہے جہاں ایک بھی بل نہ ہو۔** ایک بل موجود ہو تو صفحہ انکار کر دے گا۔ نمونہ ڈیٹا
> بعد میں پروگرام خود نہیں مٹاتا — اصل دکان میں کبھی نہ چلائیں؛ آزمائش کے لیے الگ (نئی) دکان یا بیک اپ استعمال کریں۔

## پرانی بل کی پرچی دوبارہ چھپانا

گاہک کہے "میری پرچی گم ہو گئی" تو **SELL → Bills** کھولیں:

1. اوپر بل کا نمبر، گاہک کا نام یا فون لکھیں (یا **آج / 7 دن / 30 دن** میں سے کوئی بٹن دبائیں) اور **Search**۔
2. فہرست میں سے بل پر کلک کریں — دائیں طرف اُس کی سطریں، پیسہ، رعایت، گولائی، کھاتے کا باقی اور
   واپسیاں نظر آئیں گی۔
3. **What will print** میں کاغذ حرف بحرف دکھتا ہے — آخری ہندسہ پوری طرح نظر آ رہا ہو تب ہی
   **Print this bill again** دبائیں۔
4. واپسی کی پرچی چاہیے تو Returns میں سے وہ واپسی چنیں اور **Print this return receipt** دبائیں۔

> ہر دوبارہ پرنٹ بلیک باکس میں ایک سطر لکھتا ہے (`sale_reprint`)۔ صفحہ کسی بل، اسٹاک یا کھاتے کو
> نہیں بدلتا؛ غلط بل ٹھیک کرنے کا واحد راستہ **واپسی** ہے۔ جس شخص کو بل بنانے کی اجازت نہیں،
> اُسے یہ صفحہ مینو میں نظر نہیں آتا۔

## اگر آپ Git سے اپ ڈیٹ کرنا چاہیں (ایتھر ڈویلپر کے لیے)

پہلے Visual Studio **بند** کریں، پھر `D:\areaa` میں `.vs`، `Area11.WPF`، `WPFSample` اور
`Area11.WPF.sln` کو حذف کر دیں، اور ایک بار:

```
git fetch origin
git reset --hard origin/arena/a8a3b2e0-area11a
```

> یہ کمانڈ آپ کے فولڈر کو بالکل GitHub جیسا بنا دیتی ہے۔ `START-AREA11.bat` اب خود بتا دیتا ہے
> اگر فولڈر ادھورا ہو، اس لیے یہ قدم صرف اُن کے لیے ہے جو ٹرمینل استعمال کرتے ہیں۔

## اگر Visual Studio میں `Area11.WPF.csproj` نہ ملنے کا ایرر آئے (MSB4025)

یہ ایرر **کوڈ میں نہیں** — Visual Studio کے پاس پرانا سولوشن کھلا ہے جو اب `prototypes\` میں ہے۔

### طریقہ 1 (سفارش): ڈبل کلک

`D:\areaa\tools\CHECK-AREA11.cmd` → یہ خود سب درست کر دیتا ہے۔

### طریقہ 2: ٹرمینل سے (صرف اگر ٹائپ کرنا آتا ہو)

پہلے `D:\areaa` پر جائیں — ایک ہی لائن:

```
cd /d D:\areaa
```

پھر یہ ایک لائن (پورا راستہ دیا گیا ہے، اس لیے کسی اور فولڈر میں ہونے سے فرق نہیں پڑتا):

```
powershell -NoProfile -ExecutionPolicy Bypass -File D:\areaa\tools\doctor.ps1 -Fix
```

اگر پھر بھی شک ہو کہ کیا ہو رہا ہے، یہ چلائیں (صرف پڑھتا ہے، کچھ نہیں بدلتا):

```
D:\areaa\tools\diagnose.bat
```

### طریقہ 3: Visual Studio میں صرف یہ کریں

1. Visual Studio **بند** کریں
2. `D:\areaa` فولڈر میں **`.vs`** نام کا فولڈر دیکھیں — اُسے حذف کر دیں
3. وہاں اگر **`Area11.WPF.sln`** یا **`Area11.WPF`** فولڈر ہو تو اُنہیں بھی حذف کر دیں
4. Visual Studio دوبارہ کھولیں اور **`D:\areaa\Area11.sln`** کھولیں

### یاد رکھیں

- Visual Studio میں ہمیشہ **`D:\areaa\Area11.sln`** کھولیں — `dotnet` فولڈر والا نہیں، `prototypes`
  والا نہیں۔
- `C:\ProgramData\Area11` (ڈیٹا) کو کبھی نہ چھیڑیں۔

# GitHub سے کوڈ لانا — GitHub Desktop / Visual Studio / VS Code میں چلانا

> یہ صفحہ بتاتا ہے کہ نیا کوڈ کیسے لائیں **بغیر ہر بار ZIP ڈاؤن لوڈ کرنے کے**، اور اُسے
> GitHub Desktop، Visual Studio یا VS Code میں کیسے چلائیں۔

## 0. کون سا طریقہ استعمال کریں؟ (ایک نظر میں)

| طریقہ | اپ ڈیٹ کیسے | محنت | کس کے لیے |
|---|---|---|---|
| **GitHub Desktop** ⭐ | ایک بار کلون، پھر **Fetch → Pull** | سب سے کم | آپ کے لیے سب سے آسان — ZIP دوبارہ نہیں ڈاؤن لوڈ کرنا پڑتا |
| **Visual Studio 2026** | File → Clone، پھر F5 | کم | کوڈ دیکھنا، ڈی بگ کرنا، بریک پوائنٹ لگانا |
| **VS Code** | Clone Repository، پھر F5 | کم | ہلکا ایڈیٹر، تیز کھلتا ہے |
| **ZIP** (پرانا طریقہ) | ہر بار **نیا** ZIP، نیا فولڈر | زیادہ | صرف اُس وقت جب Git بالکل نہ ہو |

**اہم:** تینوں ٹولز ایک ہی فولڈر (`D:\Area11`) استعمال کر سکتے ہیں — ایک ہی کوڈ،
ایک ہی ڈیٹابیس (`C:\ProgramData\Area11`)۔ کوئی ٹول دوسرے کا کام خراب نہیں کرتا۔

**سب سے ضروری بات:** سارا نیا کام شاخ (branch) **`arena/a8a3b2e0-area11a`** پر ہے۔
اگر آپ نے `main` شاخ کلون کی، تو پرانا کوڈ کھلے گا — نہ نیا رنگ، نہ نئی سہولتیں۔
اب `START-AREA11.bat` خود بتا دیتا ہے اگر آپ غلط شاخ پر ہیں۔

## 1. راستہ A — ZIP (آسان، Git کی ضرورت نہیں)

یہ وہی طریقہ ہے جو آپ نے استعمال کیا۔ جب نیا کوڈ آئے تو:

1. نیا ZIP ڈاؤن لوڈ کریں:
   `https://github.com/Dr-Adil-Abdullah/AREA11a/archive/refs/heads/arena/a8a3b2e0-area11a.zip`
2. **نئے** فولڈر میں ایکسٹریکٹ کریں (پرانے پر نہ کھولیں)
3. `START-AREA11.bat` پر ڈبل کلک

> نقصان: ہر بار پورا ZIP آتا ہے، اور آپ کی تبدیلیاں واپس GitHub پر نہیں جاتیں۔

## 2. راستہ B — GitHub Desktop (سب سے آسان، سفارش)

نہ ٹرمینل، نہ کمانڈ — صرف ماؤس۔

### قدم 1 — انسٹال (ایک بار)
`https://desktop.github.com` → ڈاؤن لوڈ → Install → GitHub اکاؤنٹ سے سائن اِن

### قدم 2 — کلون (ایک بار)
1. **File → Clone repository…**
2. اوپر **URL** کا ٹیب منتخب کریں
3. یہ لکھیں:
   `https://github.com/Dr-Adil-Abdullah/AREA11a`
4. **Local path** میں `D:\Area11` رکھیں
5. **Clone** دبائیں

### قدم 3 — درست شاخ منتخب کریں (یہ سب سے اہم قدم)
کلون کے بعد اوپر **Current Branch** پر کلک کریں → فہرست میں
**`arena/a8a3b2e0-area11a`** منتخب کریں → **Checkout**۔

> اگر یہ نہ کریں تو آپ `main` پر رہیں گے، جہاں پرانا کوڈ ہے۔

### قدم 4 — چلائیں
`D:\Area11` میں **`START-AREA11.bat`** ڈبل کلک۔

### قدم 5 — اگلی بار اپ ڈیٹ (جب میں کوئی نیا ورژن بھیجوں)
1. GitHub Desktop کھولیں
2. اوپر **Fetch origin** دبائیں
3. اگر لکھا آئے **Pull origin** → وہ بھی دبا دیں
4. `START-AREA11.bat` ڈبل کلک → نیا رنگ نظر آئے گا

> بس۔ نہ نیا ZIP، نہ نیا فولڈر، اور `bin`/`obj` گِٹ میں شامل نہیں اس لیے کوئی ٹکراؤ نہیں ہوتا۔
> آپ کا ڈیٹا `C:\ProgramData\Area11` میں ہے — اپ ڈیٹ اُسے **کبھی** نہیں چھوتا۔

## 2.1 راستہ C — ٹرمینل سے Git (اختیاری)

ایک بار سیٹ کر لیں، پھر اپ ڈیٹ صرف چند سیکنڈ کا کام ہے۔

### قدم 1 — Git انسٹال کریں (ایک بار)

`https://git-scm.com/download/win` → ڈاؤن لوڈ → Next, Next, Install

تصدیق: نیا ٹرمینل کھول کر `git --version` لکھیں، ورژن دکھے تو ہو گیا۔

### قدم 2 — کوڈ لائیں (ایک بار)

ٹرمینل کھولیں (یا `D:\` میں رائٹ کلک → *Open in Terminal*) اور یہ ایک لائن:

```
git clone -b arena/a8a3b2e0-area11a https://github.com/Dr-Adil-Abdullah/AREA11a.git Area11
```

اب `D:\Area11` میں مکمل کوڈ، `.git` کے ساتھ (یعنی اپ ڈیٹ بھی خود ہو سکے گا)۔

### قدم 3 — اپ ڈیٹ (جب بھی کہا جائے)

`D:\Area11` میں `START-AREA11.bat` ڈبل کلک — وہ خود `git pull` کر کے بلڈ کرتا ہے۔
یا ٹرمینل میں:

```
cd D:\Area11
git pull
```

### قدم 4 — اپنی تبدیلی واپس بھیجیں (اختیاری)

اگر آپ خود کوڈ بدلیں اور GitHub پر محفوظ کرنا چاہیں:

```
cd D:\Area11
git add -A
git commit -m "my change"
git push
```

## 3. Visual Studio میں کھولنا

1. Visual Studio کھولیں
2. **File → Open → Project/Solution…**
3. جائیں: `D:\Area11` (یا جہاں آپ نے رکھا ہے) → **`Area11.sln`** منتخب کریں → Open
4. اوپر ٹول بار میں **Area11.Desktop** منتخب ہو (Startup project)
5. **F5** دبائیں (ڈیبگ کے ساتھ چلے گا) یا **Ctrl+F5** (بغیر ڈیبگ)

> ⚠️ `dotnet` فولڈر میں کوئی `.sln` **نہیں** ہے۔ سولوشن صرف روٹ میں ہے۔
> اگر Visual Studio پرانا `Area11.WPF.sln` کھولے تو وہ غلط ہے — بند کر کے `Area11.sln` کھولیں۔

### Visual Studio میں ڈیٹابیس کہاں بنتا ہے

`C:\ProgramData\Area11\area11.db` — یہی اصل ڈیٹا ہے، کبھی حذف نہ کریں۔

## 4. VS Code میں کھولنا

1. **Extensions** میں جائیں → **C# Dev Kit** (Microsoft) انسٹال کریں
2. **File → Open Folder…** → `D:\Area11`
3. `Area11.sln` پر کلک کریں (Solution Explorer کھل جائے گا)، یا ٹرمینل میں:

```
dotnet build
dotnet run --project dotnet\Area11.Desktop
```

4. ڈیبگ کے لیے **F5** → پہلی بار "C#" منتخب کریں → وہ خود `.vscode/launch.json` بنا دے گا

## 6. رنگ بدلنا (رنگ = ورژن)

سارے رنگ **ایک ہی فائل** میں ہیں:

```
dotnet\Area11.Desktop\Resources\Theme.xaml
```

| نام | ابھی | کہاں استعمال ہوتا ہے |
|---|---|---|
| `BrandBrush` | `#E11D48` (گلابي) | بٹن، عنوان، ٹوٹل |
| `BrandDarkBrush` | `#BE123C` (گہرا گلابي) | بٹن دبانے پر |
| `BrandSoftBrush` | `#FFF1F2` (ہلکا گلابي) | پس منظر کی پٹی |

**اصول (D-24):** جب بھی کوڈ بدلے، رنگ بھی بدلے — تاکہ ایک نظر میں پتہ چلے کون سا ورژن
چل رہا ہے۔ مکمل فہرست `docs/VERSIONS.md` میں ہے۔ لاگ اِن سکرین پر ورژن اور رنگ کا نام
(`v0.2.3 · Rose`) لکھا ہوتا ہے؛ اگر وہ نیا نام دکھائے تو اپ ڈیٹ ہو چکا ہے۔

> بعد میں رنگ **Settings** سے بدلنے کی سہولت بھی آئے گی (اصول E-02: ہر چیز قابلِ تبدیل)۔

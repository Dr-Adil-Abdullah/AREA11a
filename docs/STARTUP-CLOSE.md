# Area11 کیسے چلے اور کیسے بند ہو (P16)

> Settings → Shop میں مالک تین میں سے ایک طریقہ چنتا ہے۔ یہ تحفظ **عام بند کرنے** سے روکتا ہے —
> Windows ایڈمن، Task Manager، شٹ ڈاؤن یا بجلی جانے سے نہیں۔ دکان کا ڈیٹا ان سب میں محفوظ رہتا ہے۔

---

## 1. تین طریقے

| طریقہ | شروع | × بند |
|---|---|---|
| By hand (manual) | آئیکن سے، ہاتھ سے | عام بند، کوئی سوال نہیں |
| Start with Windows (auto) | ہر Windows sign-in پر خود | عام بند، کوئی سوال نہیں |
| Protected (محفوظ) | ہر Windows sign-in پر خود | **ہر بار** پاس ورڈ/PIN مانگے |

## 2. خودکار آغاز سب اکاؤنٹ پر (v0.59.0: ایڈمن نہ ہو تو بھی چلے)

Auto اور protected اس PC کے **ہر Windows اکاؤنٹ** پر لاگو ہوتے ہیں (مالک کا فیصلہ)۔ سب پر لگانے کے لیے
**Windows administrator** چاہیے — لیکن (v0.59.0، مالک کا حکم) ایڈمن نہ ہو تو محفوظ کرنا **ناکام نہیں ہوتا**:
پروگرام صرف **اس Windows اکاؤنٹ** پر خودکار آغاز لگا دیتا ہے جس سے آپ نے save کیا، اور صفحہ صاف لکھتا ہے
کہ یہ صرف اس اکاؤنٹ پر ہے۔ سب اکاؤنٹ پر کرنا ہو تو START-AREA11 پر right-click کر کے
**Run as administrator** چلائیں، پھر Save دبائیں — پرانی اکیلی entry خود ہٹ جاتی ہے تاکہ پروگرام دو بار نہ کھلے۔
لاگ اِن پھر بھی ہر شخص کو خود کرنا ہوتا ہے — خودکار لاگ اِن کبھی نہیں ہوتا۔

**دکان کا PC اور فلمیں:** یہ پروگرام خودکار **کھلتا** ہے، دوسرے پروگرام **بند نہیں کرتا** — ملازمین کو
فلموں/کھیلوں سے روکنا Windows کی kiosk/lockdown سیٹنگ کا کام ہے، اس ایپ کا نہیں۔ وہ الگ Windows سیٹ اپ ہے۔

## 3. بند کرنے کی اجازت کس کے پاس

Protected میں × دبانے پر کھڑکی پوچھتی ہے: **نام** (خالی = مالک) اور **پاس ورڈ یا PIN**۔
بند وہی کر سکتا ہے جو (1) صحیح secret بتائے اور (2) مالک ہو یا مالک نے Staff &amp; permissions میں
**Close the program** پر ٹک لگایا ہو۔ غلط اندازے sign-in کی طرح سست ہوتے ہیں (5 غلطیوں پر تھوڑی دیر تالا)۔
ہر کامیاب اور ہر نامنظور کوشش بلیک باکس میں نام کے ساتھ لکھی جاتی ہے۔

## 4. لاگ اِن کھڑکی بھی محفوظ

Protected میں sign-in سے پہلے والی کھڑکی بھی × سے بغیر پاس ورڈ بند نہیں ہوتی (مالک کا فیصلہ)۔
Sign-out اور خودکار sign-out (idle/12 گھنٹے) پر کوئی سوال نہیں — وہ بند کرنا نہیں، صرف نام بدلنا ہے۔

## 5. پاس ورڈ بھول جائیں تو

پروگرام چلاتے وقت **Shift دبائے رکھیں**: تحفظ اتر کر manual ہو جاتا ہے اور بلیک باکس میں لکھا جاتا ہے۔
(جس کے پاس PC ہے وہ Task Manager سے ویسے بھی بند کر سکتا ہے، اس لیے یہ راستہ اسی تحفظ کے درجے کا ہے۔)

## 6. سچی حد — یہ ضرور سمجھ لیں

- Task Manager، Windows administrator، شٹ ڈاؤن یا بجلی جانا پروگرام **بند کر سکتے ہیں** — یہ تحفظ عام × سے ہے، ان سے نہیں۔
- شٹ ڈاؤن پر پروگرام سوال کیے بغیر بند ہوتا ہے تاکہ Windows رُکے نہیں۔
- ادھورا کام (drafts، ہولڈ بل) ویسے ہی محفوظ رہتا ہے؛ ایڈیٹر کی اپنی «محفوظ کیے بغیر بند؟» تنبیہ بھی ویسے ہی آتی ہے۔

## 7. جانچ (test copy + اصل PC)

پہلے `tools\RUN-TESTS.cmd`: مطلوبہ نتیجہ **`ALL GREEN - 1175 of 1175`** (v0.59.0)۔ پھر:

1. عام طریقے سے Settings → Shop کھولیں: غیر مالک کے لیے خانہ بند (disabled) ہو۔
2. بغیر ایڈمن auto save کریں: save کامیاب ہو اور صفحہ لکھے «this Windows account only»۔ پھر Run as administrator چلا کر دوبارہ save کریں: «every Windows account» ہو جائے۔ تینوں mode باری باری آزمائیں۔
3. Protected میں ×: غلط PIN رد، بغیر ٹک عملے کا صحیح PIN بھی رد («may not close»)، مالک کا PIN بند کرے۔ لاگ اِن کھڑکی پر × بھی یہی پوچھے۔
4. Sign-out پر کوئی سوال نہ آئے۔
5. Shift دبا کر چلائیں: manual بحال + بلیک باکس میں `protection_reset`۔
6. Auto/protected save کر کے Windows restart کریں (اصل PC): ہر اکاؤنٹ پر Area11 خود کھلے، لاگ اِن پھر بھی ہاتھ سے ہو۔

# Area11 انسٹال کرنا — ایک فائل، ڈبل کلک (Phase 5)

> **دکان کا ڈیٹا `C:\ProgramData\Area11` میں رہتا ہے اور کبھی نہیں مٹایا جاتا** — نہ انسٹال پر،
> نہ نئے ورژن پر، نہ اَن انسٹال پر۔ یہ فائل صرف پروگرام لاتی ہے، ڈیٹا کبھی نہیں۔

دو PC ہیں: **build والا** (جس پر کوڈ اور .NET ہے — وہیں فائل بنتی ہے) اور
**دکان والا** (جس پر دکان چلتی ہے — وہاں صرف ڈبل کلک ہوتا ہے)۔

## 1. Build والے PC پر — پہلی بار، صرف ایک بار

1. نیا کوڈ لیں (`START-AREA11.bat` خود لاتا ہے، یا GitHub Desktop → Fetch → Pull)۔
2. مفت **.NET 10 SDK** انسٹال کریں (اگر پہلے سے نہیں):
   `https://dotnet.microsoft.com/download/dotnet/10.0`
3. مفت **Inno Setup 6** انسٹال کریں (بس ایک بار — next، next، finish):
   `https://jrsoftware.org/isdl.php`
4. **`tools\MAKE-SETUP.cmd`** پر ڈبل کلک کریں (دو تین منٹ لگتے ہیں)۔
5. آخر میں یہ ایک فائل بنتی ہے (ورژن نمبر ہر بار نیا):
   `dist\Area11-Setup-v0.64.0.exe`

یہی وہ فائل ہے جو بھیجی جاتی ہے — USB، گوگل ڈرائیو یا واٹس ایپ document۔
`dist\` فولڈر git میں نہیں جاتا (بنی ہوئی چیز ہے، کوڈ نہیں)۔

## 2. دکان والے PC پر — ڈبل کلک

1. فائل کاپی کریں (مثلاً `Area11-Setup-v0.64.0.exe`)۔
2. ڈبل کلک کریں → Windows permission مانگے گا → **Yes**۔
3. next، next، finish — بس۔ ڈیسک ٹاپ اور Start menu دونوں میں **Area11** کا آئیکن بنتا ہے۔
4. آخر میں ٹک لگا ہو تو Area11 خود کھلتا ہے۔ پہلی بار لاگ اِن:
   نام `admin` + پاس ورڈ `area11` (نام خالی چھوڑنا بھی admin ہی لاگ اِن کرتا ہے) —
   پھر ایپ خود کہے گی کہ پہلے دن پاس ورڈ بدلیں۔ بدلیں ضرور۔

انسٹال کے دوران یہ سب خود ہوتا ہے (کچھ پوچھا نہیں جاتا):

- پروگرام `C:\Program Files\Area11` میں (پرانا ورژن ہو تو وہی بدلا جاتا ہے، ڈیٹا وہیں رہتا ہے)۔
- `C:\ProgramData\Area11` ہر Windows اکاؤنٹ کے لیے لکھنے کے قابل (کیشئر ایڈمن نہیں ہوتا، پھر بھی بل بناتا ہے)۔
- پرنٹ spooler چالو (رسیدوں کے لیے)۔
- ونڈوز کے ساتھ خود چلنا **آن** (ہر اکاؤنٹ پر)۔ بند کرنا ہو تو Settings → Shop۔
  اگر یہ ایک قدم ناکام ہو تو بھی انسٹال مکمل ہوتا ہے — صرف ایک اطلاع آتی ہے،
  اور Settings → Shop سے بعد میں آن ہو جاتا ہے۔
- Add or remove programs میں اندراج (ورژن + آئیکن کے ساتھ)۔

## 3. نیا ورژن آیا تو (اپ ڈیٹ)

1. Build والے PC پر نیا کوڈ + `MAKE-SETUP.cmd` → نئی فائل (مثلاً `Area11-Setup-v0.65.0.exe`)۔
2. دکان والے PC پر ڈبل کلک — وہی next، next، finish۔
3. Area11 کھلا ہو تو انسٹالر خود کہے گا پہلے بند کریں — چلتی دکان کو کبھی زبردستی نہیں مارتا۔
4. پہلی کھڑکی لاگ اِن کی ہوگی، **نئے رنگ** میں — یہی ثبوت ہے کہ نیا ورژن چل رہا ہے۔
5. بل، کھاتے، تصویریں، بیک اپ — سب ویسے کے ویسے۔ ڈیٹا کو انسٹالر چھوتا ہی نہیں۔

## 4. اَن انسٹال کرنا ہو تو

Settings → Apps → Area11 → Uninstall — یا Start menu میں Uninstall۔
پروگرام، شارٹ کٹ اور خود چلنے والی entry مٹتی ہے؛
**`C:\ProgramData\Area11` ویسے کا ویسا رہتا ہے** — ڈیٹابیس، تصویریں، بیک اپ، سب۔

## 5. پرنٹر اور اسکینر (پہلی انسٹال کے بعد ایک بار)

SYSTEM → Printer & scanner کھولیں اور پرنٹر لگا لیں (رسید کا سائز 58 یا 80)۔
اگر PC پر کوئی پرنٹر نہیں تو Windows Settings سے **Microsoft Print to PDF**
شامل کریں — رسید پھر بھی بنے گی اور PDF محفوظ ہوگی۔
پرنٹر غائب ہو تو بھی دکان نہیں رکتی (بل بنتا ہے، صرف کاغذ نہیں نکلتا)۔

## 6. رکاوٹ آئے تو (تین صورتیں، بس)

| انسٹالر کیا کہے | کیا کریں |
|---|---|
| پرانا Windows (10 سے پہلے یا بہت پرانا) | Windows update کریں یا نیا PC استعمال کریں |
| جگہ کم ہے | کچھ جگہ خالی کر کے دوبارہ چلائیں |
| start-with-Windows آن نہ ہو سکا | کوئی بات نہیں — انسٹال مکمل ہے؛ Settings → Shop سے آن کریں |

## 7. پرانا راستہ (بیک اپ)

اگر کبھی ایک فائل والا انسٹالر نہ بن سکے تو پرانا راستہ اب بھی ہے:
`tools\MAKE-INSTALLER.cmd` (zip + `INSTALL-AREA11.cmd`) — تفصیل `docs/INSTALL.md` میں۔
دونوں ایک ہی پروگرام ایک ہی جگہ انسٹال کرتے ہیں۔

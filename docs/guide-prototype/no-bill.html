نو بل / No Bill

چھ حصوں کی فہرست
یہ تین تیار شدہ نمونوں میں سے ایک ہے؛پوری کتاب نہیں۔ متن کا source-review ہوا ہے،native WPF کا source شامل ہے؛اصل Windows مدد کی عملی جانچ باقی ہے۔ پرنٹ/PDF کیلئے Ctrl+P استعمال کرسکتے ہیں۔

گاہک مال واپس لایا ہے، لیکن اصل بل ابھی دستیاب نہیں۔ یہاں واپسی کا PR ریکارڈ بنایا جاتا ہے تاکہ واپس آیا مال، دی گئی رقم اور بعد میں ملنے والا بل ایک معلوم اندراج سے جڑے رہیں۔

یہ اصل بل والی عام Return کا شارٹ کٹ یا صرف پرنٹر آزمانے کا صفحہ نہیں۔ حقیقی shop میں مشق کیلئے PR نہ بنائیں۔

یہاں کیا کیا جاسکتا ہے؟

  • واپس آئی چیز، صحیح مقدار اور یونٹ کے ساتھ PR بنانا۔
  • PR کی slip دینا یا اسی slip کی نقل نکالنا۔
  • بل کے منتظر اندراج دیکھنا، مجاز طور پر اصل بل جوڑنا اور غلط اندراج منسوخ کرنا۔
  • Linked اور cancelled اندراج کی مستقل تاریخ دیکھنا۔

کس کو اجازت ہے؟

موجودہ فعال اکاؤنٹ اور متعلقہ Returns اجازت درکار ہے۔ اصل بل جوڑنے یا اندراج منسوخ کرنے کیلئے مالک/مینیجر کی شرط بھی ہے۔ صرف بٹن نظر آنے کو مستقل اجازت نہ سمجھیں۔

نیا PR بنانے کا طریقہ

  1. سیل → No Bill کھولیں اور اصل واپس آئی چیز تلاش کریں۔
  2. صحیح Quantity اور Unit دیں، پھر Add this item کریں۔
  3. Tray کی چیزیں اور کل مقدار اصل مال سے ملائیں۔
  4. دستیاب customer شناخت، واقعی واپس دی گئی رقم اور وجہ/نوٹ درست لکھیں۔
  5. دوبارہ جائزہ لے کر Save and give the slip کریں۔
  6. کامیاب نتیجہ اور PR نمبر پڑھیں، پھر slip دیں۔

اصل بل مل جائے تو

  1. درست PR منتخب کریں۔ مالک/مینیجر اصل INV نمبر دے، یا Find bills سے تلاش کرے۔
  2. شناخت اور چیزیں ملائیں؛ صرف ملتے جلتے نام پر بل نہ جوڑیں۔
  3. درست نتیجہ چن کر Use the selected bill، پھر Attach this bill کریں۔
  4. نتیجہ اور warnings پڑھیں۔

بل جوڑنے سے وہی stock اور refund دوبارہ نہیں لگتے۔ Alert کے معاملے کی بندش الگ مجاز عمل ہوسکتی ہے۔

غلط اندراج منسوخ کرنا

درست PR پہچانیں، واضح Cancel reason لکھیں اور مجاز منسوخی کریں۔ مطلوبہ stock باقی نہ ہو تو عمل رک سکتا ہے۔ Cancel خود گاہک سے نقد رقم واپس وصول ہونے کا اندراج نہیں کرتا۔

کیا نہیں ہوسکتا؟

  • Slip نہ نکلنے پر وہی واپسی نیا PR بنا کر دوبارہ درج کرنا۔
  • بل جوڑ کر دوبارہ refund یا stock حاصل کرنا۔
  • Slip پھاڑ کر مستقل ریکارڈ مٹانا یا cancellation سے منفی stock بنانا۔

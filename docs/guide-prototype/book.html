کاغذ کی چوڑائی، printer کا نام، Auto-print، cutter، bulk format، PDF folder اور copies بدل سکتے ہیں، بشرطیکہ متعلقہ Settings تبدیلی کی اجازت ہو۔

• Save settings: مجاز ترتیبات محفوظ کرنے کی درخواست۔

• Print selected: متعلقہ فہرست میں منتخب set کیلئے؛ موجودہ bulk setting کا مطلب پڑھیں۔

• Print test slip: الگ Printer & scanner صفحے کی hardware جانچ، کاروباری bill نہیں۔

# Production کا منصوبہ — debug سے دکان تک (Phase 5 + صفائی + کیوسک + پورشن 1 مکمل، v0.67.0)

مالک کا حکم: تینوں فکس (نام+ائیکن، startup، expense) کے بعد ایپ کو جانچ کے موڈ سے نکال کر
**اصل دکان والی ایپ** بنایا جائے — ایک فائل، ڈبل کلک پر انسٹال، permission مانگے، دوسرے PC پر
بھیجی جا سکے۔ مالک نے Phase 1 **بدل دیا**: پہلا کام اسکرین لاک ہے (v0.60.0 میں مکمل)، باقی
مرحلے آگے کھسک گئے۔ ہر مرحلے کے بعد مالک سے جواب، اور آخری build سے پہلے
واضح اجازت ("بنا دوں؟")۔

## Phase 1 — اسکرین لاک (مکمل، v0.60.0 Basalt)

- چلانے پر لاگ اِن کھڑکی خود کھلے؛ × پاس ورڈ مانگے، پیچھے نہ ہٹے
- چھوڑنے/چھوٹا کرنے کی کوشش پر پہلے چھوٹا "not allowed" باکس + اسکرین واپس کھینچے
- ہر فرار بلیک باکس میں: کون، کب، کتنی دیر (`screen_left`)؛ Task Manager سے بند اگلے
  اسٹارٹ پر پکڑا جائے (`session_killed`)؛ عام بندش پر خاموشی
- لاک پہلے سے **بند (off)** ہے — مالک Settings → Shop میں ٹک کرے تو چلے؛ جسمانی جانچ باقی

## Phase 2 — فالتو کوڈ + پاس ورڈ کے دروازے (مکمل، v0.61.0 Taupe)

- فہرست `docs/DEAD-CODE-REVIEW.md` میں، پھر مالک کے اکٹھے جواب پر عمل
- چھوٹا فالتو ہٹا (5 methods، 14 keys)؛ 3 keys پرانی دکانوں کے لیے رکھیں
- Staff ٹیب سے PIN/پاس ورڈ بدلے؛ "forgot password" سے recovery word پر مالک لاگ اِن
- جسمانی جانچ باقی

## Phase 2 کا پرانا نام — فالتو کوڈ کی فہرست (اوپر مکمل)

- پورا کوڈ پڑھ کر فالتو/مردہ حصے **ایک طرف لکھنا** (ابھی کچھ نہیں ہٹانا)
- پھر **اکٹھے سوال**: "فلاں فلاں چیز کا کیا کروں؟" — مالک بتائے گا ہٹانا ہے یا نہیں
- جو واضح بے فائدہ ہو اسے رپورٹ میں الگ لکھنا

## Phase 3 — پیسے کی درستگی (مکمل، v0.62.0 Moss)

- سات اصول کوڈ + ٹیسٹ سے ثابت: رعایت کی حد، راؤنڈ ڈاؤن، بقایا، زائد وصولی، واپسی کی حد، ڈراؤر فارمولا، ایک تحریر میں کھاتے
- ایک اصل خامی ملی اور ٹھیک ہوئی: سپلائر کی ڈیلیوری ادائیگی ہمیشہ کیش لکھی جاتی تھی — اب \"کس طرح\" (کیش/آن لائن/کارڈ) پوچھا جاتا ہے، بینک والی ڈراؤر سے نہیں کٹتی
- کھاتے کی حد والا تالا اب Settings میں ٹک ہے (کیشئر رکتا ہے، مالک/مینیجر کبھی نہیں)؛ ٹیکس بند، پوائنٹ شرح وہی
- جسمانی جانچ باقی

## Phase 4 — اصل زندگی کے حادثے (مکمل، v0.63.0 Copper)

- درست ملے: بجلی/کریش (WAL + sync، بحالی سے پہلے safety بیک اپ)، پرنٹر بند پر بھی سیو،
  دوسرا کاؤنٹر خالی دکان نہیں بناتا؛ startup مرمت بھی شامل (SecurityException)
- نیا: ایک دکان ایک کاپی (دوسری پر ایک جملہ + بند؛ ماری ہوئی کاپی رکاوٹ نہیں)
- نیا: روزانہ بیک اپ آن (نئی + پرانی دکان؛ بند کرنے کا ٹک موجود)
- دوسرے کاؤنٹر کی live جانچ موخر (مالک: بعد میں)؛ pin شدہ شارٹ کٹ کا پرانا ائیکن
  ونڈوز کی حد ہے، جسمانی جانچ باقی

## Phase 5 — انسٹالر اور permissions (مکمل، v0.64.0 Pine)

- نیا: `tools/MAKE-SETUP.cmd` + Inno اسکرپٹ = **ایک فائل `Area11-Setup-vX.exe`**،
  ڈبل کلک، permission سوال، next-next-finish (سادہ انگریزی)
- شارٹ کٹ دونوں جگہ؛ انسٹال کے بعد خود چلنا آن؛ ProgramData کبھی نہیں چھوتا
  (انسٹال/اپ ڈیٹ/اَن انسٹال)؛ پرانا zip راستہ بیک اپ
- اردو گائیڈ `docs/INSTALL-URDU.md` لکھی؛ اصل setup build اور test-PC
  انسٹال/اپ ڈیٹ/اَن انسٹال باقی (مالک کے PC پر)

## آخری صفائی — پروفیشنل ایپ (مکمل، v0.65.0 Gold)

- پہلا لاگ اِن admin + area11 (seed + migration 033؛ خالی نام بھی admin؛ اپنا نام محفوظ)
- لاگ اِن سے ورژن بیج گیا (ونڈو ٹائٹل میں ورژن رہا تاکہ اسکرین شاٹ پہچانا جائے)
- ٹیسٹ مشینری نکلی (checker میں پابندی، git سے واپسی ممکن؛ حتمی فیصلہ ٹیسٹ رزلٹ پر)
- کریش/لاگ/پرنٹر ٹیسٹ رہے (پروفیشنل ضرورت)؛ اصل زندگی کا ٹیسٹ باقی

## کیوسک لاگ اِن (مکمل، v0.66.0 Crimson)

- auto-start دکان پر سائن اِن پوری اسکرین + ٹاسک بار واقعی غائب (manual پر عام ونڈو، مین اسکرین اچھوتی)
- حفاظت: بندش پر واپسی، اسٹارٹ پر مرمت، exit پر زبردستی، کریش باکس اوپر
- ڈائیلاگ کریش مرمت شامل؛ اصل پرکھ باقی (انسٹال کے بعد فل اسکرین + ٹاسک بار واپسی)

## مالک کا نیا بیچ — 4 پورشن (پورشن 1 مکمل v0.67.0، باقی "next" پر)

- پورشن 1 (مکمل): سیٹنگز ٹیب مرمت + لاک کروم (minimize غائب، ٹاسک بار چھپی)
- پورشن 2: ٹائم — بیچ درستگی UI (صحیح بڑا + اصل چھوٹا، دونوں بلیک باکس) + بڑا فرق قبول
- پورشن 3: ڈی ورکشاپ — آخری صفائی، اوریجنل ایپ جیسی (recon + اکٹھے سوال + صفائی)
- پورشن 4: ڈاکس — پہلے مکمل پلان، پھر ہر پورشن کی سمری + تفصیل، ہر "next" پر اگلی قسط

## Phase 6 — آخری اجازت اور build

- پانچوں مرحلوں کی رپورٹ ایک جگہ: کیا دیکھا، کیا ٹھیک کیا، کیا باقی خطرہ ہے
- مالک سے پوچھنا: "کیا میں اصل دکان والی فائل بنا دوں؟"
- "بنا دو" پر build + رپورٹ؛ اس کے بعد مالک مکمل ٹیسٹ کرے گا

## اصول (ہر مرحلے پر)

- دکان کا اصل ڈیٹا کبھی چھونا نہیں — سب test copy پر
- ہر دعویٰ ٹیسٹ یا ہاتھ کے چیک سے ثابت؛ جو ثابت نہ ہو وہ "نامعلوم" لکھنا، "ٹھیک ہے" نہیں
- ورژن + رنگ ہر build پر بدلے گا تاکہ فائلیں آپس میں نہ گڈمڈ ہوں

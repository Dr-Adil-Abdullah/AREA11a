> **کیا باقی ہے** اور **کیا فیصلے کیے گئے**۔ ہر بڑے کام کے بعد یہ فائل اپ ڈیٹ ہوگی۔

آخری اپ ڈیٹ: **2026-10-19** · ورژن **0.2.0 (بنیادی ڈھانچہ + خریداری + POS بلنگ)**

## 2. اس ورژن میں کیا مکمل ہے

1. **ڈیٹابیس** — مکمل ریفرنس اسکیما (26 ٹیبل): products, batches, customers, suppliers,
   purchases, sales, payments, shifts, expenses, returns, quarantine, stock movements,
   stock-take, alerts, audit, custom fields۔ WAL موڈ، ٹرانزیکشن، ترتیب وار مائیگریشن۔
2. **لاگ اِن اور رولز** — مالک = پاس ورڈ (خالی نام)، ملازم = نام + PIN۔
   PBKDF2-SHA256 ہیش، 5 ناکام کوششوں پر وقفہ، لاگ اِن کا آڈٹ۔
3. **پروڈکٹس** — تلاش (نام/بارکوڈ/سالٹ/ریک/کمرہ)، کیٹگری فلٹر، کم اسٹاک فلٹر،
   نیا پروڈکٹ، ترمیم، پیک فارمولا (1 Box = X Strip = Y Unit)، کاسٹ/ریٹیل/VIP/ڈاکٹر ریٹ،
   نئی کیٹگری اور نئی کمپنی اسی فارم سے (U-18)۔
4. **سیٹنگز** — 45 کلیدیں، سب ڈیٹابیس میں، تلاش کے ساتھ، ہر تبدیلی آڈٹ میں۔
5. **ڈیش بورڈ** — آج کی بکری، آج کے بل، پروڈکٹس، کم اسٹاک، ایکسپائری، اسٹاک ویلیو۔
6. **بلیک باکس** — کس نے، کب، کس ماڈیول میں، **پرانی قدر → نئی قدر**۔ کبھی ڈیلیٹ نہیں ہوتا۔
7. **نمبرنگ** — ایک ہی جگہ سے: `INV-0001` · `PINV-0001` · `RET-0001` · `Q-0001` · `SR-0001` · `PR-0001` · `ST-0001`
   (کاؤنٹر ٹیبل، اسی ٹرانزیکشن میں — دو کاؤنٹر ایک ہی نمبر نہیں لے سکتے)۔
8. **خریداری (PINV)** — سپلائر، بیچ نمبر، ایکسپائری (ماہ یا مکمل تاریخ)، کاسٹ/ریٹیل،
   **سیمپل/بونس لائن (0 لاگت)**، اسٹاک میں فوری اضافہ، سپلائر کھاتہ، جزوی ادائیگی، آڈٹ۔
9. **POS بلنگ** — FEFO (قریب ترین ایکسپائری پہلے)، Box/Strip/Unit، کاؤنٹر پر ہی کل رقم،
   رعایت (مارجن/ریٹیل + رول کی حد + لاگت سے نیچے نہیں)، راؤنڈ آف نیچے + لاگت کا تحفظ،
   نقد → **باقی (change)**، ادھار → گاہک کا کھاتہ، **منفی اسٹاک صرف الرٹ** (بکری نہیں رکتی)۔
   **بل کا ٹوٹل ہمیشہ = تمام آئٹم لائنوں کا جوڑ** (راؤنڈ آف اور ٹیکس لائنوں میں تقسیم)۔

## 4. فیصلے (ڈیفالٹ — مالک کی تصدیق کے لیے کھلے ہیں)

| سوال | ابھی کیا فرض کیا گیا |
|---|---|
| .NET ورژن | **.NET 8 LTS** |
| ڈیٹا ایکسیس | **Microsoft.Data.Sqlite** (کوئی ORM نہیں) |
| پراجیکٹ کی شکل | **ایک ہی WPF پراجیکٹ** (Views / ViewModels / Services / Models / Utils / Data) |
| UI انداز | **صاف WPF + ایک مشترک Styles.xaml** (کوئی تھرڈ پارٹی تھیم نہیں) |
| رسید پرنٹ | **دونوں** (تھرمل ESC/POS + A4 PrintDialog) — رسید کے مرحلے پر |
| پہلا ماڈیول | **بنیادی ڈھانچہ** (یہ ورژن) |
| زبان | UI **انگریزی** (Q-07)، دستاویزات اردو |

اگر مالک کوئی اور انتخاب چاہیں تو صرف بتائیں — تبدیلی ایک جگہ ہوگی۔

## 5. اہم اصول جو کوڈ میں لاگو ہیں

1. **پیسہ = انٹیجر پیسا** (`long`)، فارمیٹ صرف UI پر (`FormatHelper`)۔
2. **راؤنڈ آف صرف نیچے** اور **لاگت سے نیچے نہیں** (`MoneyHelper.ApplyRoundDownWithCostGuard`)۔
3. **منفی اسٹاک کام نہیں روکتا** — صرف الرٹ (U-30) — POS کے مرحلے پر لاگو ہوگا۔
4. **کچھ ڈیلیٹ نہیں ہوتا** — `active` / ریورسنگ رو۔
5. **ہر تبدیلی آڈٹ میں** — پرانی قدر → نئی قدر، ماڈیول کے ساتھ۔
6. **کوئی سیکریٹ کوڈ میں نہیں** — سب `appsettings.json` سے۔
7. **سروسز UI پر exception نہیں پھینکتیں** — `OperationResult` + لاگ + دوستانہ پیغام۔

## 6. چلانے اور جانچنے کا طریقہ

```
Windows 10/11 + .NET 8 SDK
cd Area11.WPF
dotnet run
```

پہلا لاگ اِن: نام **خالی**، پاس ورڈ **`area11`**۔
پہلے ہی دن پاس ورڈ بدلیں (Settings → اگلے ورژن میں سٹاف مینجمنٹ)۔

ڈیٹا: `bin/Debug/net8.0-windows/data/area11.db`
لاگ: `bin/Debug/net8.0-windows/data/logs/app-YYYY-MM-DD.log`

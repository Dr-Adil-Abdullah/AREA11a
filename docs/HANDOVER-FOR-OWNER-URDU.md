## ۴ — نئے ایجنٹ سے کیا توقع رکھیں

- وہ **`TAKEOVER.md` سے شروع کرے گا** اور پہلی بات یہ پوچھے گا: `git pull` کے بعد `tools\RUN-TESTS.cmd`
  اور `tools\INSTALL-AREA11.cmd` کا مکمل کنسول بھیجیں۔
- وہ آپ سے **اردو میں** بات کرے گا، آپ کے پیغام کی زبان کے مطابق؛ رومن اردو میں نہیں۔
- کوئی فیصلہ مانگنا ہو تو **ایک ہی پیغام** میں `سوال / Question:` اور `Possible Options: A / B / C / D`
  کی صورت میں پوچھے گا، اور ہر جواب `docs/OWNER-DECISIONS.md` میں لکھے گا۔
- ہر کوڈ تبدیلی کے ساتھ **نیا رنگ اور نیا نام** آئے گا (آپ کا اصول)۔
- کبھی یہ نہیں کہے گا "بن گیا" جب تک آپ کے کمپیوٹر پر ثابت نہ ہو۔
- **`C:\ProgramData\Area11` کو کبھی نہیں چھیڑے گا۔** کوئی ڈیمو ڈیٹا بھی نہیں (یہ آپ کا فیصلہ ہے)۔
- سرخ ٹیسٹ کو ٹیسٹ بدل کر ہرا نہیں کرے گا — کوڈ ٹھیک کرے گا، اور وجہ `docs/VERSIONS.md` میں لکھے گا۔
